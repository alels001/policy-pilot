# Procedure: Handling Nonconforming Parts (8D)

Nordwerk Automotive GmbH · Version 3.2 · valid from 2025-11-01 · Owner: Quality Management
Document no.: QM-VA-007

## 1. Purpose
This procedure defines how nonconforming parts are handled and how root causes are eliminated with the 8D method.

## 2. Immediate actions
2.1 Block the affected parts in the ERP system and move them to the quarantine area.
2.2 Check whether parts are already in production or shipped to customers (containment).
2.3 Inform the responsible quality engineer within **2 hours** for safety-relevant parts, otherwise within 1 working day.

## 3. The 8D steps
- D1: Build the team
- D2: Describe the problem
- D3: Containment actions
- D4: Root cause analysis (e.g. 5-Why, Ishikawa)
- D5: Choose corrective actions
- D6: Implement and verify corrective actions
- D7: Prevent recurrence (update FMEA, control plan, work instructions)
- D8: Close and recognize the team

## 4. Deadlines for supplier complaints
- D3 (containment) within **24 hours**
- D4 (root cause) within **10 working days**
- Complete 8D report within **30 working days**

## 5. Documentation
All 8D reports are stored in the QM system and are evidence for IATF 16949 audits.
